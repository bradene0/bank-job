# web (TypeScript, React, Vite, dnd-kit)

Game UI, replay mode, Under the hood panel. Built in M4. Accessibility: WCAG 2.2 AA; drag-and-drop also works by keyboard and tap.

```
pnpm install --frozen-lockfile    # Node 26 (see .nvmrc), pnpm 10
pnpm dev                          # http://localhost:5173
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```
